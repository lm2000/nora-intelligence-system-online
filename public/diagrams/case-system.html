Read the full diagram description
  • Nora / OpenClaw: A good conversation or voice interface can stay separate from the knowledge and model service. Fresh direct-client sanity checks remain pending.
  • Direct NIS API: Coordination owns Responses and Chat Completions plus existing HTTP, AG-UI and FastMCP interfaces. A supported protocol subset is not every possible client feature.
  • Deep Agents / LangGraph: LangChain connects models directly. Default execution uses one model, with at most two independent branches when requested. All branches share limits.
  • Three providers: The target retains three providers. Live synthetic compatibility passed; comparative quality, billed cost and client latency remain unmeasured.
  • Retrieval MCP: BGE encodes queries and documents. Qdrant finds passages; prepared text supplies source reads. Search and read pin the same release. This is vector RAG, not a knowledge graph.
  • Allowlisted tools: Composio brokers explicitly configured app accounts; MCP exposes explicitly selected tools. Schemas and action-specific approval constrain writes.
  • PostgreSQL: Checkpoints preserve conversation execution. Explicit confirmed memories have provenance. Neither replaces the prepared source corpus.
  • Manual ingestion: Four separate operator-triggered jobs update knowledge. They do not start from an ordinary conversation. Additions assemble with retained corpus; source meaning is not rewritten.
