# Boutique Marketing Agency preview

Standalone presentation-based preview. It is intentionally not linked from the main site navigation.

- `index.html`: overview with in-page presentation and video dialogs.
- `presentation.html`: browser-readable slides.
- `walkthrough.html`: full video player.
- `assets/`: slide images.
- `media/`: presentation and full walkthrough; the quick pitch is excluded.

This is a preview, not the completed main-site redesign. No login is implemented.
